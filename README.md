# SOC Detection Lab

Welcome to my SOC Detection Lab!

This repository documents my hands-on learning and practical work in Security Operations, focusing on security monitoring, threat detection, alert investigation, and incident response.

I use this repository to develop and demonstrate my understanding of SOC workflows, Microsoft security technologies, KQL queries, and security investigation methodologies.

## Objectives

- Develop practical skills in Security Operations Center (SOC) workflows.
- Create and understand security detection rules using Kusto Query Language (KQL).
- Explore Microsoft Sentinel and Microsoft Defender capabilities.
- Investigate suspicious activities and simulated security incidents.
- Understand threat hunting and incident response processes.
- Document investigation findings and recommended remediation steps.

## Tools and Technologies

| Technology | Purpose |
|---|---|
| Microsoft Sentinel | SIEM and security monitoring |
| Microsoft Defender | Threat detection and investigation |
| KQL | Security analytics and detection queries |
| Microsoft Purview | Data security and protection concepts |
| Wiz CSPM/CNAPP | Cloud security posture concepts |
